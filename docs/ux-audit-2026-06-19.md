# Frontend UX audit — 2026-06-19

Five parallel read-only audits (visual, accessibility, responsive/mobile,
interaction/states, code-quality) of `index.html`, synthesized and prioritized.
Implemented items are committed in groups after this doc.

## Convergent themes (flagged by multiple audits)

1. **The empty / accumulating-season state is the entire current experience.**
   With 0 captured days, the live page is a blank map, `0/0` stats, a generic
   placeholder spotlight, and 13 greyed cards — indistinguishable from a broken
   page. (visual TOP PICK, interaction TOP PICK, +3 more findings.)
2. **Timezone correctness bug.** `minutesAfterMidnight`/`fmtTime`/`fmtShortDate`
   read the *viewer's* local clock, not Pacific. Non-Pacific viewers see wrong
   departure times, off-by-a-day date labels, and — worst — `filterToDepartureWindow`'s
   ≥14:00 gate can strip the real departure, yielding "departure n/a" on correct
   data. Critical once published. (code TOP PICK + 3 highs.)
3. **Pending vs scheduled are indistinguishable**, and blanket `opacity:0.6` on
   greyed cards drops chip text under WCAG AA. (visual, a11y, interaction.)
4. **Departure time is encoded by color only** — no text alternative for the
   legend scale (WCAG 1.4.1). (a11y TOP PICK.)
5. **Three overlapping card affordances** (whole-card click vs checkbox vs Focus),
   which is also invalid nested-interactive ARIA. (interaction, a11y.)
6. **Mobile peek shows drawer chrome, not content** — a contradictory "Close"
   button on a closed drawer, the FAB overlapping it, a non-draggable grabber,
   and sub-44px touch targets. (responsive TOP PICK.)

## Prioritized plan

**P0 — correctness (must-fix before publishing)**
- Timezone: compute Pacific wall-clock via `Intl.DateTimeFormat(timeZone:"America/Los_Angeles")`
  in `minutesAfterMidnight`, `fmtTime`, `fmtShortDate`.

**P1 — the empty-state experience (highest UX value)**
- Real zero-captured empty state: season-status spotlight + map note explaining
  "cards light up as each Friday sails; first track after Jun 19."
- Differentiate pending ("Sailed · processing", amber) vs scheduled ("Upcoming",
  neutral); fix greyed-card contrast; vessel-tinted accent; one-line list legend.
- State-aware guidance (don't tell users to "spotlight one" when nothing exists).

**P2 — accessibility + interaction clarity**
- `aria-live` on `#status` and `#routeDetail`; legend `role=img` + descriptive
  `aria-label`; map note pointing to the list as text alternative.
- Route-list header hint ("Check to plot · click to spotlight · Zoom to fit");
  relabel "Focus" → "Zoom"; disable Earliest/Latest/Fit/Recent/All when nothing
  is captured.

**P3 — low-risk code/perf cleanups**
- Geofence toggle → `updateGeofenceVisibility` (not full `render`).
- `fitBoundsForRoutes` empty fallback → `meta` bounds (so "Fit" after "None" works).
- Remove redundant `renderDetail`/`chooseActiveRoute` calls per render cycle.

**P4 — visual polish**
- Style Leaflet zoom controls + attribution for the dark theme.
- Legend bar: match the five `departureColor` stops; taller; endpoint ticks.
- Muted empty stat values (`—` in `--soft`, not bold dashes).

**P5 — mobile**
- Peek: hide "Close" while closed, hide the redundant FAB while the handle shows,
  raise `--drawerPeek` so content peeks; `overscroll-behavior:contain` on panel +
  list; ≥44px touch targets at the mobile breakpoint; fit padding from live drawer
  height; `aria-expanded` on the drawer toggles.

## Deferred (taste-dependent or higher-risk — flagged for review)

- Deep restructure of the three-affordance card model (kept additive clarity for
  now; full redesign needs a design call).
- Wholesale type-scale / vertical-rhythm overhaul (did targeted bumps only).
- Drawer drag-to-open gesture (kept tap-toggle; relabeled affordances).
- Side-sheet layout on landscape phones.
